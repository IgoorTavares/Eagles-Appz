LABZ AI — senha do papel labz_borda

Esta página não usa a internet. A senha é criada aqui no seu navegador e não é enviada a ninguém. Não mande a senha pelo chat. Guarde-a só no seu gerenciador de senhas e no segredo LABZ_DB_URL do Supabase.

1. Senha (guarde no seu gerenciador de senhas)

2. Comando para o SQL Editor do Supabase (leva só o verificador, NÃO a senha)

3. Conexão para o segredo LABZ_DB_URL (leva a senha)

Passo a passo

  1. Copie a senha para o seu gerenciador de senhas.
  2. No Supabase, abra SQL Editor, cole o comando do item 2 e clique em Run.
  3. Confira o endereço do pooler (item 3) e guarde a LABZ_DB_URL no gerenciador também (ela vai para o segredo das funções na etapa 5).
  4. Feche esta página. Ao abrir de novo, ela gera outra senha (a anterior não fica guardada aqui).
  5. Depois de colar, copie qualquer outro texto para "limpar" a área de transferência (se o seu computador guarda o histórico da área de transferência, apague a senha de lá).
  6. Prefira abrir esta página numa janela anônima, sem extensões, e sem compartilhar a tela.

Segredo do worker (LABZ_WORKER_SEGREDO)

Independente da senha acima. 64 caracteres aleatórios (0–9 e a–f), criados aqui no navegador, sem internet. Guarde no gerenciador de senhas: ele vai para o segredo LABZ_WORKER_SEGREDO (Etapa 5) e, com o mesmo valor, para o cofre do Supabase como labz_worker_segredo (Etapa 10).
